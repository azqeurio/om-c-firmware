# db firmware

올림푸스 / OM SYSTEM 마이크로 포서드 카메라에 추가 기능을 넣기 위한 유저 제작 패치 툴입니다 (**v0.4.5**, 24기종 / 26개 프로파일 지원).

[English](./README.md) | [한국어](./README.ko.md) | [작동 현황 및 릴리스 노트](https://db-firmware-support.vercel.app) | [전체 기종×기능 표](https://db-firmware-support.vercel.app/overview)

## 사용 전 꼭 읽어주세요

- **이 프로그램에는 OM SYSTEM, Olympus의 어떠한 펌웨어도 포함되어 있지 않습니다.** 유저가 만든 기능 추가용 패치 툴이며, 사용자가 직접 받은 순정 펌웨어를 로컬 PC에서 수정하는 방식으로 동작합니다.
- **실기기 테스트 범위에 대해:** 제가 직접 보유하고 있는 **OM-1, OM-5 Mark II, E-M10 3종**은 실기기에서 테스트한 뒤 배포할 수 있지만, **그 외 나머지 기기들은 오프라인 시뮬레이션으로만 체크한 것입니다.** 이 점을 반드시 감안하고 사용해 주세요.
- **책임 한계:** 이 툴을 통해 펌웨어를 업데이트하다가 카메라가 고장 나거나 문제가 생겨도 저는 책임을 지지 않습니다. 배터리를 충분히 충전하고 순정 펌웨어를 백업한 상태에서 **본인의 책임으로 설치해 주시기 바랍니다.**
- **사용 후 피드백을 남겨주시면 큰 도움이 됩니다.** 사용 뒤 화면에 나오는 피드백 창(또는 [작동 현황 페이지](https://db-firmware-support.vercel.app))에 결과를 적어주시면, 제가 가지고 있지 않은 기기들까지 현재 어떤 기능이 잘 되고 안 되는지 다 같이 확인할 수 있습니다.

## 프로그램 기본 기능

**Windows (x64)**와 **macOS (Apple Silicon, macOS 15.0+)**용 단일 실행 빌드를 제공하며, 한국어/영어 UI를 지원합니다.

- 공식 순정 펌웨어를 바로 내려받거나 로컬 `.BIN` 파일을 불러와 패치할 수 있고, 원복용 순정 백업 저장(SHA-256 검증)도 지원합니다.
- 원하는 기능만 골라 오프라인으로 패치한 뒤 SD 카드 업데이트용 폴더(`DCOLYMP/`)를 만들어 줍니다.
- **SD LUT 편집·변환기**: `.cube`, `.xmp`, `.lrtemplate` 및 프리셋을 카메라 색 모델 기준으로 변환하고, RAW/사진 미리보기 후 SD 카드에 바로 저장합니다.
- **전자셔터 사운드 편집기**: `WAV / MP3 / FLAC / M4A / OGG` 음원(최대 5초)을 불러와 파형 구간 편집, 연사 속도별(`12.5 / 16.7 / 25 / 50 fps`) 미리듣기, 프리셋 저장/불러오기가 가능합니다.
- `?` 창에서 최신 릴리스 노트와 기종별 작동 현황을 보고 익명으로 테스트 결과를 보낼 수 있습니다(펌웨어 파일이나 PC 경로는 전송되지 않습니다).

## 지원 기능 정리

### 펌웨어 포트 (2개 프로파일)
- **OM-1 → OM-1 Mark II 포트**
  기존 OM-1 바디에서 OM-1 Mark II (`FW 1.3`) 펌웨어를 구동하며(Live GND, 인물 AF 등), 연사 버퍼 확장(**85매** / 물리 RAW 93슬롯 / +160 MiB)이 적용되어 있습니다. 한국어, 파나소닉 조리개링, Wi-Fi 5 GHz, 전자셔터 사운드, Quasi LUT(화면 Q 배지·선택 바·무선 동기화 포함), 하이브리드 셔터를 지원합니다.
  *(최초 설치 시와 OM-1 순정 복귀 시 카메라 설정이 초기화됩니다.)*
- **OM-5 → OM-5 Mark II 포트** *(시험용)*
  기존 OM-5 바디에서 OM-5 Mark II (`FW 1.1`) 펌웨어와 신규 메뉴 UI를 구동합니다. 한국어, 파나소닉 조리개링, 적외선(IR) 레드-블루 채널 스왑을 지원합니다.
  *(최초 설치 시와 OM-5 순정 복귀 시 카메라 설정이 초기화됩니다.)*

### Quasi LUT — SD 카드 · 모바일 앱 (4개 프로파일: TruePic X)
*OM-1 (1.9), OM-1 Mk2 포트 (1.9), OM-1 Mark II (1.3), OM-3 (1.1)*
- 채널 혼합, 암부/명부 색조, 12색 HSL, 블랙/화이트 포인트, 257포인트 R·G·B·전체 밝기 곡선, 6색 채도/색조 및 RGB 출력 게인 조절을 추가합니다(모노크롬 제외).
- **컬러 필름 그레인**: OM-3 흑백 프로파일의 필름 그레인(약/중/강)을 컬러 정지화상 촬영에 적용합니다(아트필터 제외).
- 펌웨어에는 Q-LUT 엔진만 한 번 넣고, 실제 LUT는 SD 카드에 **최대 8개(`Q1`~`Q8`)**까지 넣어 재플래싱 없이 바꿔 쓸 수 있습니다.
- 버튼에 `[Q-LUT]`을 지정해 짧게 누르면 켜기/끄기, 누른 채 다이얼을 돌리면 슬롯 전환이 되며 렌치 메뉴의 `Quasi LUT`에서도 고를 수 있습니다. 전원을 껐다 켜도 마지막 상태와 슬롯이 유지됩니다.
  - OM-1 Mark II와 OM-1 Mk2 포트는 화면 상시 `Q1..Q8` 배지와 선택 바(최대 18자 이름)를 지원하고, OM-3는 Q-LUT 버튼+다이얼 조작 시 선택 바가 뜹니다(순정 OM-1은 버튼·다이얼과 메뉴로 사용).
- [db_link Android 앱](https://play.google.com/store/apps/details?id=com.dblink)과 무선 연결해 SD 카드의 LUT를 폰에서 바로 편집·순서 변경·삭제할 수 있습니다.

### 하이브리드 셔터 (9개 프로파일)
*OM-1 (1.9), OM-1 Mk2 포트 (1.9), OM-1 Mark II (1.3), OM-3 (1.1), OM-5 (1.2), OM-5 Mark II (1.1), E-M1X (2.4), E-M1 Mark III (1.6), E-P7 (1.1)*
- 드라이브 모드 단사 옆에 **하이브리드(`H□`)**를 추가합니다.
- 기계 셔터 한계(`1/8000초`, E-P7은 `1/4000초`)까지는 기계 셔터로 찍다가 더 빠른 셔터가 필요할 때 자동으로 전자 셔터(최고 `1/32000초`, E-P7은 `1/16000초`)로 전환합니다.
- P/A Auto ISO에서는 확장 저감도로 내려가기 전에 전환하고, S/M에서는 하이브리드 선택 시에만 다이얼이 고속 전자 셔터 영역까지 열립니다.
- 전원을 껐다 켜도 마지막 드라이브 모드가 유지되며, 다른 드라이브 모드나 플래시·벌브/라이브타임·동영상·고해상도·Live ND·플리커 스캔은 순정 그대로 동작합니다.

### 파나소닉 렌즈 조리개링 지원 (25개 프로파일)
*E-M5 (2.3)를 제외한 전체 25개 프로파일*
- 물리 조리개링이 있는 파나소닉 라이카 / 루믹스 렌즈를 **A/M 모드**에서 사용할 수 있게 해줍니다.
- A/M 모드에만 적용되어 P/S 모드에서 링을 돌려도 노출이 틀어지지 않으며, 링이 없는 렌즈는 기존처럼 바디 다이얼로 제어됩니다.

### 적외선(IR) 레드-블루 채널 스왑 (22개 프로파일)
*TruePic X 4개 프로파일(OM-1, OM-1 Mk2 포트, OM-1 Mark II, OM-3)을 제외한 22개 프로파일 전체*
- IR 개조 카메라용으로 하드웨어 3×3 색 행렬의 R과 B 채널을 실시간으로 바꿉니다.
- 라이브뷰, JPEG, 동영상, 카메라 내 RAW 현상에 모두 적용되며 원본 ORF RAW 데이터와 MakerNote는 그대로 유지됩니다.
- 모노톤, 모노크롬 프로파일(`MONO 1/2/3`), 흑백·세피아 아트필터는 자동으로 순정 상태를 유지합니다.

### 한국어 메뉴 및 글꼴 (7개 프로파일)
*OM-1 (1.9), OM-1 Mk2 포트 (1.9), OM-1 Mark II (1.3), OM-3 (1.1), OM-5 (1.2), OM-5 Mk2 포트 (1.2), OM-5 Mark II (1.1)*
- 카메라 메뉴와 도움말을 한국어로 바꿉니다.
- 순정 OM-1에서는 글꼴·크기·굵기·자간 조절도 가능하고, OM-5 Mk2 포트는 일본어/중국어 번체/중국어 간체 중 바꿀 언어를 고를 수 있습니다.

### 전자셔터 사운드 (4개 프로파일: TruePic X)
*OM-1 (1.9), OM-1 Mk2 포트 (1.9), OM-1 Mark II (1.3), OM-3 (1.1)*
- 렌치 메뉴 아래에 커스텀 사운드 3슬롯(`Off / 1 / 2 / 3`)과 음량 6단계(`0~5`: `0%`~`100%`)를 추가합니다.
- AF와 MF/PreMF 모드 모두에서 재생됩니다(SH1 / ProCap SH1 제외, 실제 연사 속도 영향 없음).

### Wi-Fi 5 GHz 핫스팟 (6개 프로파일)
*OM-1 (1.9), OM-1 Mk2 포트 (1.9), OM-1 Mark II (1.3), OM-5 (1.2), E-M1X (2.4), E-M1 Mark III (1.6)*
- 카메라 기본 AP 모드를 5 GHz(채널 36)로 전환합니다. 기기 순정 국가 코드 설정은 그대로 따릅니다.

### Auto ISO 최저 셔터속도 (6개 프로파일 + E-P7)
*E-M5 (2.3), E-M5 Mark II (4.1), E-M10 (1.4), E-M10 Mark II (1.4), E-M10 Mark III (1.2), E-M10 Mark IV (1.1), 그리고 E-P7 (1.1) 컨트롤 팩 포함*
- 순정에 없던 P/A 모드 Auto ISO 최저 셔터속도 메뉴, 설정 저장, 노출 반영 기능을 추가합니다.

### 기종별 전용 기능
- **OM-1 (`1.9`) — SH2 / ProCap SH2 속도 추가**: `12.5 / 16.7 / 25 / 50 fps`를 추가하고, 50 fps 미지원 렌즈에서도 `12.5 / 16.7 fps`를 고를 수 있게 메뉴 제한을 풀었습니다.
- **E-M1X (`2.4`) — ISO Auto 상한 25600**: Auto ISO 상한 메뉴와 내부 AE 클램프를 ISO 6400에서 ISO 25600으로 올립니다.
- **E-P7 (`1.1`) — 버튼·노출·메뉴 기능 팩**: 상단 바로가기 및 본체 버튼 리매핑, 십자키 커스터마이징(ISO/WB/AF 위치/드라이브 기본 또는 방향별 할당), AF 홈 이동(Set Home 불러오기, 미저장 시 중앙 단일 타겟 폴백), M + Auto ISO 노출보정(버튼+다이얼), 다이얼 방향 설정, Auto ISO 최저 셔터속도 메뉴, 확장 한글 글꼴(569자)을 묶어 제공합니다.

## 사용 방법

1. [Releases](../../releases)에서 본인 OS에 맞는 `db firmware 0.4.5` 파일을 받습니다:
   - Windows (x64): `db firmware 0.4.5.exe`
   - macOS (Apple Silicon, macOS 15.0+): `DBFirmware-macOS-AppleSilicon-0.4.5.zip` *(미서명 빌드라 Gatekeeper 차단이 뜨면 우클릭 → 열기로 실행)*
2. 기종 프로파일을 고르고 순정 펌웨어를 받거나 불러옵니다. 만약을 대비해 순정 백업도 하나 저장해 두세요.
3. 필요한 기능을 체크하고, 필요하면 SD LUT / 셔터 사운드 / 글꼴 옵션을 맞춥니다.
4. 생성된 `DCOLYMP/` 폴더를 포맷한 SD 카드 최상위에 복사합니다.
5. 배터리를 완충한 뒤 SD 카드 업데이트로 설치하고, 끝날 때까지 전원을 끄지 마세요.
6. 설치해서 써 보신 뒤에는 프로그램 안의 피드백 창(`?`)이나 [작동 현황 페이지](https://db-firmware-support.vercel.app)에 결과를 남겨주시면 기종별 현황 파악에 큰 도움이 됩니다.
